# FoloToy AI Passport 桌面时钟

这是一款面向 FoloToy AI Passport 的 Wi-Fi 桌面时钟与 FMO 电台伴侣。主界面集中显示本地时间、天气、头像、当前通联信息和所选 FMO 服务器。

## 功能

- 显示日期、本地时间、Wi-Fi 状态和电量；联网后同步时间。
- 根据已配置的经纬度显示当前天气、温度、风况和天气图标；天气每 30 分钟更新一次。
- 连接 FMO 服务，显示当前通联呼号、QTH、本地网格到通联者的方位和距离。通联结束后，如果没有新的通联，信息保留 5 秒。
- 读取 FMO 收藏服务器列表。短按上、下键可切换收藏服务器，屏幕上的服务器名称随之更新。
- 支持通过手机配网和设置本地位置，包括 Wi-Fi 扫描和头像上传。
- 一分钟没有新通联后，自动进入黑底省电界面，仅显示时间；新通联或短按任意按键可唤醒并返回主界面。

## 首次配置

1. 打开设备。在主界面长按**确认键（OK）**进入设置。
2. 用手机连接设备屏幕显示的 Wi-Fi 网络。网络名为 `FoloToy-Clock-` 加设备 Wi-Fi MAC 地址末四位；固定密码是 `12345678`。
3. 手机保持连接设备热点，在浏览器中打开 `http://192.168.4.1`。
4. 在配置页扫描附近的 Wi-Fi，或手动填写 Wi-Fi 名称和密码。密码输入框默认明文显示。
5. 填写 Maidenhead 定位网格、十进制度数格式的纬度和经度、省份、城市，以及 FMO 服务器主机名或 IP 地址。FMO 地址只填写主机名或 IP，不要填写 `ws://` 或路径。
6. 点击**保存并重连**。设备会保存配置并检查 Wi-Fi 连接；如果连接失败，请保持在配置页，修正配置后重新提交。
7. 更换头像时，在**更换头像**区域选择图片并点击**保存头像**。浏览器会从图片中心裁剪正方形并缩放到屏幕尺寸。返回主界面后即可看到已保存的头像。

之后需要修改设置时，可随时在主界面长按**确认键（OK）**进入配置；配置页打开时再次长按确认键可退出。

## 按键操作

| 操作 | 功能 |
| --- | --- |
| 短按**上键** | 切换到上一个 FMO 收藏服务器 |
| 短按**下键** | 切换到下一个 FMO 收藏服务器 |
| 双击**下键** | 按 25%、50%、75%、100% 循环调节屏幕亮度 |
| 长按**确认键（OK）** | 打开或关闭手机配置页 |
| 省电界面短按任意键 | 唤醒并返回主界面 |

亮度设置会保存在设备中。收藏列表为空或服务器连接不可用时，切换按键不会生效；使用上下键前，请先在 FMO 中设置收藏服务器。

## 网络与数据

时间同步、天气和远程 QTH 查询需要可用的 Wi-Fi 网络。配置的 FMO 主机也必须能从该网络访问，并提供 FMO 通联事件和服务器 WebSocket 服务。服务器名称与收藏列表由 FMO 提供；设备本身不会编辑收藏列表。

Wi-Fi 账号、本地位置、屏幕亮度和头像保存在设备 NVS 中，正常重启后会保留。将合并固件写入 `0x0` 可能覆盖设备已保存的 NVS 数据，刷写后可能需要重新配网并上传头像。

## 固件刷写

请使用对应固件版本提供的**合并完整镜像**，从 `0x0` 开始刷写。合并镜像包含 bootloader、分区表和应用；单独的应用 `.bin` 不能写入 `0x0`。安装 `esptool` 并替换为正确串口号后，可参考：

```sh
python -m esptool --chip esp32c3 --port COMx --baud 460800 write_flash --flash_mode dio --flash_freq 80m --flash_size 8MB 0x0 FoloToy-AI-Passport-full.bin
```

刷写前请核对固件发布说明中的确切文件名和 SHA-256。刷写会替换固件，并可能影响已保存的配置；刷写流程不会自动保留或备份旧固件。

## 常见问题

- **没有时间或天气：**检查 Wi-Fi 和互联网连接；时间同步和天气服务离线时不可用。
- **FMO 显示未连接：**检查 FMO 主机名或 IP 是否正确，以及配置的 Wi-Fi 是否能访问该主机。
- **没有通联者位置或距离：**确认对方提供了 Maidenhead 网格或 QTH，并检查本地网格和经纬度是否正确。
- **无法进入配置页：**返回主界面长按确认键；打开 `http://192.168.4.1` 前，先让手机连接设备热点。
- **刷写后配置或头像消失：**重新连接设备热点并保存；合并镜像可能覆盖 NVS 内容。
